The Model

OEE = A × P × Q

85%
WORLD-CLASS BENCHMARK

OEE (Overall Equipment Effectiveness) is the gold standard KPI for measuring manufacturing productivity. It answers one question: of all the time a machine could have been making good parts at full speed, what fraction actually was?

Most plants operate between 40–60%. The gap to world class (85%) represents recoverable capacity — no new investment required, just eliminating the 6 Big Losses systematically.

OEE = A × P × Q
// All three must be high — one bad component tanks OEE

Availability = Run_Time / Planned_Time
// Penalizes unplanned stops and setups

Performance = (Ideal_CT × Count) / Run_Time
// Penalizes minor stops and slow running

Quality = Good_Count / Total_Count
// Penalizes scrap, rework, startup losses

// MTBF = (Available_Time − Σ Breakdown_Duration) / n_failures
// MTTR = Σ Breakdown_Duration / n_failures
TPM Framework

The 6 Big Losses

Every OEE loss maps to one of these six categories — the universal language of Lean manufacturing.

Availability Loss
01
Equipment Failure
Unplanned breakdowns — the machine stops unexpectedly. Largest source of lost time in most plants.
↓ Availability
Availability Loss
02
Setup & Adjustment
Planned changeovers, tool changes, product transitions. Reducible via SMED (Single Minute Exchange of Die).
↓ Availability
Performance Loss
03
Idling & Minor Stops
Short stoppages under 5 minutes — jams, sensor faults, material shortages. High frequency, hard to track manually.
↓ Performance
Performance Loss
04
Reduced Speed
Machine running below design speed. Often hidden — operators slow down to avoid defects or manage wear.
↓ Performance
Quality Loss
05
Process Defects
Scrap and rework produced during steady-state production. Each bad part = one takt time wasted.
↓ Quality
Quality Loss
06
Reduced Yield
Startup losses — defects produced during warmup, stabilization, or after changeover before process is stable.
↓ Quality

KPI Library

Every metric computed

MTBF

4.2h
= run_time / n_failures

Mean Time Between Failures — average operating time between two consecutive breakdowns. Higher is better.

MTTR

22 min
= Σ repair_time / n_failures

Mean Time To Repair — average duration to restore operation after a breakdown. Target: ↓ via standardized maintenance procedures.

Scrap Rate

7.6%
= scrap / total_parts

Fraction of non-conforming parts in total production. Directly impacts Quality component and material cost.

Takt Time

45 s
= available_time / demand

Ideal cycle time — the heartbeat of the production line. Performance is measured against this theoretical optimum.

Codebase

5-module architecture

[ DATA ]
Simulator
simulator.py
Poisson-distributed breakdowns, log-normal durations, binomial quality. Multi-machine, multi-shift.
[ OEE ]
Calculator
calculator.py
OEE, Availability, Performance, Quality. MTBF, MTTR. Shift-level and machine-level aggregation.
[ OEE ]
Losses
losses.py
6 Big Losses decomposition. Waterfall chart data. Category totals (availability / performance / quality).
[ LEAN ]
Pareto + Report
pareto.py · report.py
ABC classification, vital few identification, trend analysis, anomaly detection (z-score flagging).
[ UI ]
Dashboard
app.py
Streamlit: live gauge, 6-loss stacked bar, Pareto chart, machine comparison, OEE trend, anomaly table.
48 unit tests · pytest + CI (Python 3.10 & 3.11) · Mathematical invariants: OEE = A×P×Q enforced, parts_good ≤ parts_total, all rates ∈ [0,1], Pareto cumulative monotone, ABC classification exhaustive · Perfect-shift test: synthetic zero-loss shift verifies OEE → 1.0 · Zero-production test: pure-breakdown shift verifies OEE = 0
Usage

Running in 3 commands

01 — INSTALL

Setup

# Clone repo
git clone https://github.com/
  alaaeddinethr/oee-dashboard
cd oee-dashboard

# Install
pip install -r requirements.txt

# Run tests
pytest tests/ -v
02 — SIMULATE

Generate data

# Simulate 15 shifts, 4 machines
python src/data/simulator.py \
  --shifts 15 \
  --machines M01 M02 M03 M04

# Compute OEE report
python src/oee/calculator.py \
  --data data/production_events.csv

# Pareto analysis
python -c "from src.lean.pareto import *"

  src/dashboard/app.py
